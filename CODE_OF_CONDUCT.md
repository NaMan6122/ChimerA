# Code of Conduct

This project adapts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

- **Be technical, not personal.** Critique code, wire protocols, and design —
  never people.
- **Disagreements end in measurements.** This repo's culture is "measured,
  not asserted": bring numbers, captures, or reproduction steps.
- **No soliciting for credential material.** Never ask another contributor
  for exported sessions, cookies, or account access — yours are
  password-equivalent, and so are theirs.
- **Respect vendor boundaries.** Discussion of reverse-engineering findings
  is expected here; sharing *someone else's* credentials, bypassing human
  captchas, or building multi-account abuse tooling is not.
- No harassment, trolling, or spam of any kind.

## Scope

Applies to the repository, its issue tracker, PRs, and any project space.

## Enforcement

Report violations through [private vulnerability reporting](https://github.com/NaMan6122/ChimerA/security/advisories/new)
(for security-adjacent conduct) or by contacting the maintainer directly.
The maintainer may remove, edit, or reject comments, commits, PRs, and
issues that violate this standard. Repeated or severe violations result in a
permanent block.
